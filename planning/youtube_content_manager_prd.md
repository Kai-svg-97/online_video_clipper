# YouTube 콘텐츠 관리 GUI 애플리케이션 기획서

## 프로젝트 명
YouTube Content Manager & Downloader

---

## 개요
본 프로젝트는 유튜브 콘텐츠를 즐겨찾기 기반으로 관리하고 다운로드 및 라이브러리화할 수 있는 GUI 애플리케이션을 개발한다. 단순 다운로드 툴을 넘어 개인 유튜브 콘텐츠 관리 플랫폼을 목표로 한다.

---

## 주요 기능 요약

- 즐겨찾기 관리 (제목, 태그, 설명, 개인 메모)
- 다운로드 및 다운로드 이력 관리
- 카테고리 기반 저장
- 태그 및 검색 필터링 (SQLite FTS5 전문 검색)
- 썸네일 UI 및 크기 조절 (그리드 / 리스트 뷰 전환)
- 탐색기(TreeView) 기반 UI
- 자막/썸네일/메타데이터 다운로드
- 클립보드 자동 감지
- 병렬 다운로드 및 큐 관리
- 클립 구간 추출 (ffmpeg 연동)
- 채널 구독 & 신규 영상 모니터링
- 플레이리스트 / 채널 일괄 다운로드
- 내보내기 / 가져오기
- 통계 대시보드

## 기능 상세

### 1. 즐겨찾기 & 라이브러리 관리

- URL 입력 또는 클립보드 자동 감지로 영상 추가
- 제목, 태그, 카테고리, 개인 메모 편집
- 시청 여부(watched) 표시 및 필터
- 즐겨찾기 목록 JSON/CSV 내보내기
- 유튜브 플레이리스트 URL로 일괄 임포트
- 브라우저 북마크(HTML) 임포트

### 2. 다운로드

- 단일 영상 다운로드 (품질/포맷 선택: mp4, mkv, mp3 등)
- 플레이리스트 전체 다운로드 (이미 다운로드된 항목 자동 스킵)
- 채널 아카이브 모드 (전체 또는 날짜 범위 지정)
- 병렬 다운로드 큐 (동시 다운로드 수 설정)
- 메타데이터 / 자막 / 썸네일 개별 다운로드
- 다운로드 실패 시 자동 재시도 (재시도 횟수 설정)

### 3. 클립 구간 추출

- 영상의 특정 구간 타임스탬프 북마크 저장
- ffmpeg로 해당 구간만 추출·저장
- 클립 미리보기 썸네일 자동 생성

### 4. 재생 연동

- 더블클릭 → 외부 플레이어(VLC, mpv, Windows 기본 플레이어) 실행
- 마지막 재생 위치 기억 (`last_position_sec` SQLite 저장)
- 온라인 스트리밍 재생 (다운로드 없이 yt-dlp stream URL로 재생)

### 5. 채널 구독 & 모니터링

- 채널 URL 등록 → RSS 또는 폴링으로 신규 영상 자동 감지
- 채널별 자동 다운로드 규칙 (키워드 조건, 최소/최대 재생시간 필터)
- 시스템 트레이 알림: 새 영상 발견 시 알림

### 6. 검색 & 필터

- SQLite FTS5 전문 검색 (제목, 설명, 메모 대상)
- 복합 필터: 날짜 범위, 영상 길이, 채널, 다운로드 여부, 즐겨찾기
- 저장된 검색 쿼리 (북마크된 필터)

### 7. 통계 대시보드

- 총 다운로드 수 및 누적 용량
- 카테고리/태그별 분포 차트
- 최근 활동 로그

### 8. 설정

- 기본 다운로드 경로
- 동시 다운로드 수 (1~8)
- 기본 품질/포맷 프리셋
- ffmpeg 실행 파일 경로
- 클립보드 감지 활성화 여부
- 프록시 설정
- yt-dlp 자동 업데이트 확인
- **가사 출처 관리**: 노래 가사를 조회할 사이트 목록(LRCLIB·Genius·멜론·벅스·지니 등)의 사용 여부·조회 순서 조정, 커스텀 출처 추가/삭제

### 9. 노래 정보

노래 영상에 대해 가수·앨범·제목·가사를 조회·관리한다.

- **노래 탭**: 상세화면 4번째 탭. 가수/앨범/노래 제목/발매년도 + 가사 섹션으로 구성.
- **자동 판별 + 수동 토글**: YouTube Music 카테고리 또는 음악 메타데이터로 노래를 자동 감지하고, "노래로 표시" 토글로 수동 지정도 가능.
- **가사 병행 표기**: 비한국어 노래는 원문 1줄 + 한글 번역 1줄을 병행 표기(무료 웹번역). 한국어 노래는 원문만.
- **관리형 출처 체인**: 주요 가사 사이트를 레지스트리로 관리하고, 우선순위 순으로 이어서 조회해 부족한 항목을 채운다. 참조 가능한 출처가 늘어나면 정보가 보강된다.
- **등록 시 조회 + 정보 갱신**: 등록 시 노래 정보를 조회해 기록하고, 정보 갱신(⟳) 버튼으로 재수집한다. 상세화면에서 가사는 가사 검색 버튼을 눌러야 조회하며(자동 조회 안 함), 이미 가사가 있으면 다음 출처부터 순환 조회한다.
- **단건 등록 시 자동 보강**: 영상을 한 건씩 등록하면 음원용 영상은 **가사**를, 그 외 영상은 **Gemini 요약**을 백그라운드에서 자동으로 채운다(설정으로 끌 수 있고 기본 ON). 판정 기준은 등록 시 기록된 노래 여부(YouTube Music 카테고리 또는 음악 메타데이터)다. 가사를 찾지 못하면 요약으로 대체하지 않는다. 재생목록·채널 일괄 가져오기는 대상이 아니다(영상당 수십 초가 걸려 대량 처리에 부적합). 요약은 YouTube 로그인 쿠키가 필요하다.
- **더블클릭 편집**: 가수/앨범/제목/발매년도·가사 각 영역을 더블클릭해 직접 수정할 수 있으며, 수정한 값은 이후 갱신에서 덮어쓰지 않는다.

| 항목 | 요구사항 |
|------|---------|

| Python | 3.10 이상 (배포 패키지에는 Python 번들링) |
| ffmpeg | 배포 패키지에 ffmpeg 바이너리 동봉 (`bin/`) |

| 플랫폼  | 형식                          | 도구                          |
|---------|-------------------------------|-------------------------------|
| Windows | `.exe` 설치 파일              | PyInstaller + Inno Setup      |

  - Windows: `%APPDATA%\YouTubeContentManager\`
  - Linux: `~/.local/share/YouTubeContentManager/`

## UI/UX 개선 사항 (v0.4 반영)

### 썸네일 자동 다운로드
- `AddVideoHandler`에서 yt-dlp 메타데이터의 `thumbnail` URL을 가져와 `THUMBNAIL_DIR/{video_id}.jpg`로 저장
- `YtDlpAdapter.download_thumbnail(video_id, thumbnail_url)` 메서드 추가
- `VideoAggregate.update_metadata(thumbnail_path=...)` 호출로 경로 저장
- 썸네일 다운로드 실패 시 무시하고 진행 (선택적)

### 영상 목록 — 카테고리 열 표시
- `VideoDTO`에 `category_name: str` 필드 추가 (기본값 `""`)
- 핸들러에서 카테고리 목록을 조회해 `_to_dto(agg, cats)` 형태로 전달
- 테이블 뷰: "카테고리" 컬럼 추가
- 목록 뷰 delegate: 채널·재생시간 옆에 카테고리명 표시

### 인플레이스 상세 보기 (모달 → 인라인 전환)
- `LibraryPanel` 우측 콘텐츠 영역을 `QStackedWidget`으로 변경
  - 페이지 0: 기존 비디오 목록 (툴바 + 뷰 전환)
  - 페이지 1: `_VideoDetailWidget` (내장 위젯, 다이얼로그 아님)
- 더블클릭 / "상세정보" 버튼 → 페이지 1 전환
- 상세 보기 좌상단 `← 목록으로` 버튼 → 페이지 0 복귀
- 기존 `VideoDetailDialog` (modal QDialog) 제거

### 미리보기 패널 초기화
- `QListView` 빈 공간 클릭 감지 (`_VideoListView` 서브클래스, `empty_clicked` 시그널)
- `empty_clicked` → `_PreviewPane.clear()` 호출
- 미리보기 초기 상태: "영상을 선택하세요" 플레이스홀더

### 재생 버튼 중복 제거 (UX 단순화)
- **문제**: `InlinePlayer._Controls`(▶/⏸, ■)와 외부 `▶ 재생` 버튼이 각각 존재
- **해결**: 외부 `▶ 재생` 버튼 제거; `InlinePlayer._Controls`를 단일 컨트롤 바로 통일
- 컨트롤 바 구성: `▶/⏸` · `■` · 진행 슬라이더 · 시간표시
- `🌐 브라우저에서 보기`는 컨트롤 바 외부의 별도 버튼으로 유지

### 상세 보기 레이아웃 개선
- 우측 메타데이터 영역 모든 QLabel에 `setWordWrap(True)` 적용
- 태그를 클릭 가능한 버튼 칩 형태로 렌더링
- 태그 클릭 → 해당 태그의 영상 목록 필터링 (`vm.set_tag_filter([tag_id])`)

### 좌측 패널 — 태그 목록 추가
- 카테고리 트리 하단에 `--- 태그 ---` 구분선 추가
- 태그를 알파벳/가나다 오름차순으로 `QListWidget`에 나열
- 태그 클릭 → 해당 태그 영상 필터링
- `LibraryViewModel.tags_changed` 시그널 수신 시 자동 갱신

### 태그 목록 및 영상 필터링 연동
- `vm.set_tag_filter([tag_id])` 호출로 영상 목록 필터링
- 미리보기·상세 보기의 태그 클릭도 동일 메서드 사용
- 필터 해제: 카테고리 트리에서 "전체 영상" 클릭 또는 태그 재클릭

### "로컬" 루트 — 카테고리 영상 전체 보기
- 사이드바 "📁 로컬" 헤더, 카테고리 트리 "전체 영상", 경로 바 "로컬" 세그먼트 클릭(= `set_category_filter(None)`) 시
  **카테고리에 속한 영상 전체**(`category_id IS NOT NULL`)만 표시한다.
- **미분류 영상**(카테고리 미지정)과 **재생목록 전용 영상**(재생목록에만 있고 카테고리 없음)은 제외된다.
  재생목록 전용 영상은 해당 재생목록 뷰에서 본다(재생목록 뷰는 `categorized_only` 미적용 — `video_ids` 필터로 카테고리 무관 표시).
- 구현: `SearchQuery.categorized_only` 플래그 → `videos.category_id IS NOT NULL` WHERE 절. `GetVideosQuery`/`SearchVideosQuery`를 거쳐 `LibraryViewModel._filter_categorized_only`(기본 진입 뷰 = True)가 제어한다.

### v1.1 — 구독 채널 UX 통합

1. **구독 채널 트리 + 피드 통합**: 별도 "구독 피드" 사이드바 메뉴를 제거하고, 라이브러리 좌측 YouTube 트리에 "구독 채널" 폴더와 "전체 구독 피드" 노드를 둔다. 채널 노드를 클릭하면 해당 채널의 최신 영상이 메인 영역에 피드 카드로 표시된다(`fetch_channel_videos`). 구독 채널 목록은 채널 모니터링의 구독을 공유하며, yt-dlp 가져오기에 페이지네이션을 적용해 전체 구독이 노출된다.
2. **재생목록 내 태그 필터**: 재생목록을 본 상태에서도 태그를 클릭하면 재생목록∩태그 교집합으로 좁혀 볼 수 있다.
3. **검색 안정화**: 검색어를 FTS5 구문으로 안전 변환해 `-`·`(` 등 특수문자 입력 시 구문 오류가 발생하지 않는다.
4. **다운로드 이력 정리**: 완료 이력 탭은 영상 파일만 표시(썸네일·.part 제외)하고 완료/실패를 배지로 구분한다. 통계의 총 용량은 경로 중복 제거 + 영상 파일 한정으로 정확히 집계한다.

### v1.2 — 구독 피드 채널 표시 & 채널 목록 뷰

1. **YouTube 구독 가져오기 안정화**: 구독 일괄 등록이 멱등(이미 등록된 채널 재등록 시 `UNIQUE` 충돌 없이 건너뜀)하고, API가 제공한 채널 id·name을 그대로 사용해 채널당 메타데이터 재조회 없이 빠르게 완료된다. → 진행 중 멈춤·동기화 누락 해소.
2. **전체 구독 피드 채널명 표시**: 피드 카드 썸네일 좌측 하단에 채널명 배지를 표시하고 제목 아래 채널명 라벨을 둔다. yt-dlp 플랫 추출은 구독 피드에서 채널 정보를 주지 않으므로, 영상 ID로 YouTube Data API `videos.list(part=snippet)`를 배치 역조회해 채널명을 채운다(미인증 시 구독 저장소 channel_id→이름 매핑으로 보강).
3. **개별 채널 피드는 채널명 숨김**: 특정 채널의 영상 목록에서는 이미 채널을 알고 있으므로 카드의 채널 배지·라벨을 표시하지 않는다(`show_channel` 토글).
4. **"구독 채널" 노드 = 채널 목록 그리드**: 좌측 트리의 "구독 채널" 노드를 클릭하면 등록된 채널을 아바타 + 구독자수 + 영상수 카드 그리드로 보여준다(YouTube API `channels.list(part=snippet,statistics)`). 채널 카드를 클릭하면 해당 채널 영상 피드로 이동한다. "구독 채널" 노드에는 자식이 있을 때 펼침 세모(▶/▼)가 표시된다.
5. **피드 그리드 리사이즈 재정렬**: 카드 그리드가 창 너비 변화에 따라 열 수를 재계산해 재배치된다(`resizeEvent` + 한 칸 폭 `minimumSizeHint`).

### v1.3 — 영상 목록 통일 · 상세화면 YouTube화 · 태그 스코핑

1. **영상 목록 단일 클릭 진입 + 미리보기 패널 제거**: 카테고리·재생목록·피드·채널 어디서든 영상을 **한 번 클릭**하면 곧바로 상세화면으로 전환한다(기존 더블클릭 폐지). 단일 클릭으로 중복되던 우측 미리보기 패널은 제거한다. Ctrl/Shift 클릭은 다중 선택·드래그 재정렬을 위해 선택 동작으로 유지한다.
2. **스트리밍 전용 상세**: 라이브러리에 저장되지 않은 구독 피드/채널 영상은 URL을 직접 스트리밍 재생하는 상세화면으로 연다(`load_stream`). 로컬 파일이 없으므로 클립 추출·메모·태그 편집은 비활성화한다.
3. **상세화면 YouTube 시청 페이지 레이아웃**: 좌측에 큰 플레이어와 그 아래 제목·채널·조회수·업로드일·태그·설명, 하단에 다운로드/메모/클립 탭을 두고, 우측에 연관 영상 목록을 둔다.
4. **클릭 가능한 타임라인(챕터)**: 설명에서 `MM:SS`/`HH:MM:SS` 타임스탬프를 추출(2개 이상일 때)해 챕터 목록으로 렌더하고, 클릭 시 `InlinePlayer.seek_to_ms`로 해당 위치로 재생 이동한다.
5. **컨텍스트별 연관 영상 목록**: 우측 목록은 보고 있던 분류에 따라 달라진다 — 카테고리/재생목록 영상은 현재 보고 있던 목록(같은 카테고리·재생목록, 자기 자신 제외), 피드/채널 영상은 같은 채널의 최근 영상(현재 로드된 피드 기준). 연관 영상 클릭 시 로컬/스트리밍 상세로 재진입한다.
6. **인기 태그 트리 스코핑**: 인기 태그를 현재 트리 노드 범위로 집계한다 — 카테고리는 해당 서브트리, 재생목록은 그 영상들, 둘 다 없으면(로컬 루트) 라이브러리 전체. 구현: `IVideoRepository.list_tags_with_counts(category_ids=, video_ids=)` 스코프 인자 + `GetTagsQuery` + `LibraryViewModel.refresh_scoped_tags()`. 로컬 태그가 없는 피드/채널 뷰에서는 인기 태그 패널을 숨긴다.

1. **song 바운디드 컨텍스트 신설**: Video와 1:1인 `SongInfo`(가수·앨범·제목·발매년도·가사·is_song) + `LyricsSource`(가사 출처 레지스트리). 도메인→앱→인프라→GUI 전 계층 구현.

### v1.4+ — 사이드바 트리 정리 & 통계 채널 섹션

1. **접을 수 있는 YouTube 구독 섹션**: 좌측 트리에서 로컬 섹션과 YouTube 구독 섹션을 나누던 수직 스플리터를 제거하고, 삼각형(▸/▾) 토글 바로 대체한다. YouTube 구독 섹션은 **기본적으로 접혀(숨겨져)** 있고 토글 바를 눌러 펼친다. 접혀 있을 때는 로컬 카테고리 트리가 그 공간을 차지한다.
2. **트리 기본 1레벨 표시**: 모든 트리(로컬·YouTube)는 로드 후 최상위(1레벨) 항목만 보이고 하위는 접힌 상태로 시작한다. 하위는 사용자가 펼침 화살표를 눌러야 나타난다.
3. **통계 — 채널별 카테고리 섹션**: 통계 대시보드에 채널 섹션을 추가한다. 라이브러리 영상을 **업로더 채널별**로 묶고, 각 채널이 속한 **카테고리 전체 경로 + 영상 수**를 나열한다(예: `IT채널 : IT > News (3), IT > Device (2)` / `AI초보 : AI > Coding > Claude Code (12), AI > Coding > Codex (5)`). 카테고리 링크를 클릭하면 좌측 카테고리 트리를 클릭한 것과 동일하게 라이브러리 해당 카테고리로 화면 전환한다. 이후 **뒤로가기**를 누르면 라이브러리 자체 탐색 이력을 먼저 되짚고, 소진되면 통계 화면으로 복귀한다. 집계는 `videos`를 `channel_name`·`category_id`로 GROUP BY(카테고리 지정 영상 한정)하고, 카테고리 경로는 부모 체인을 거슬러 조립한다.

### v1.5+ — 구독 채널 재동기화

1. **"구독 채널" 노드 새로고침 메뉴**: 좌측 YouTube 트리의 "구독 채널" 노드를 **우클릭하면 컨텍스트 메뉴 맨 위에 "⟳ 새로고침 (YouTube 구독 재동기화)"** 항목이 뜬다. 클릭하면 `MonitoringViewModel.import_from_youtube()`로 YouTube 구독 전체를 다시 조회해 로컬 DB에 반영한다(멱등 등록이라 기존 채널은 건너뛰고 새 채널만 추가). 완료 시 `subscriptions_changed`로 좌측 트리가, `import_yt_finished`로 채널 카드 그리드가 각각 갱신돼 유튜브 웹에서 새로 구독한 채널이 즉시 나타난다. → 기존에는 구독 목록이 로컬 DB 스냅샷이라 채널 모니터링 패널의 "가져오기" 버튼으로만 재동기화할 수 있었던 불편 해소.

### v1.8+ — 등록 시 요약·가사 자동 보강

1. **성격에 따른 자동 보강**: 영상을 단건으로 카테고리에 등록하면 등록 직후 백그라운드에서 한쪽만 채운다 — 음원용 영상이면 상세 "노래" 탭의 **가사**를, 그 외 영상이면 "요약" 탭의 **Gemini 요약**을 채운다. 노래 영상의 가수·앨범·제목·발매년도는 등록 시점에 이미 기록되므로 실질적으로 가사만 추가된다.
2. **폴백 없음**: 가사를 찾지 못해도 요약으로 넘어가지 않는다. 이미 값이 있는 영상은 건너뛴다.
3. **일괄 임포트 제외**: 재생목록·채널 일괄 가져오기는 대상이 아니다. Gemini 요약 추출이 영상당 브라우저를 띄워 수십 초 걸리므로 수백 건 임포트에 걸면 끝나지 않는다.
4. **직렬 실행 + 상태 표시**: 보강은 동시 1건으로 직렬화하고(브라우저 병렬 실행 방지), 진행·실패를 상태바에 표시한다. 완료 시 그 영상 상세가 열려 있으면 즉시 반영된다.
5. **설정 토글**: 설정 일반 섹션의 "등록 시 요약·가사 자동 채우기"로 끌 수 있다(기본 ON). 요약은 YouTube 로그인 쿠키가 필요하며 Chrome 127 이상은 쿠키 파일을 직접 등록해야 한다.

### v1.9+ — 밝은 테마 전환 & 트리 재설계

1. **기본 테마를 밝은 중간 톤으로**: 화면 전체가 너무 어둡고 창 배경·패널·카드가 서로 구분되지 않던 문제를 해결한다. 새 `mist` 팔레트를 기본값으로 하며, 계층 간 명도 차이를 눈에 보이는 수준으로 벌린다. 기존 어두운 테마 6종은 설정에서 계속 선택할 수 있다.
2. **좌측 사이드바가 패널로 분리**: 사이드바가 창 배경과 같은 색이라 경계가 없던 문제를 고친다. 이제 한 단계 밝은 면과 경계선으로 구분된다.
3. **칩·활성 태그 바가 테마를 따르도록**: 태그 칩과 활성 태그 바는 색이 코드에 고정돼 있어 어떤 테마를 골라도 어두운 색으로 남았다. 테마 색상에서 파생하도록 바꾼다. 단 "영상 없음" 경고 뱃지와 YouTube 강조색은 의미·브랜드 색이라 유지한다.
4. **태그·카테고리 색상 고정**: 같은 태그가 앱을 켤 때마다 다른 색으로 표시되던 문제를 수정한다. 이제 이름이 같으면 항상 같은 색이다.
5. **카테고리 트리 외형 재설계**: 둥근 행 배경, 카테고리별 색상 점, 우측 정렬 개수 뱃지, 즐겨찾기 별, 넉넉한 행 높이, 계층을 보여주는 들여쓰기 가이드선을 적용한다. 펼침·드래그&드롭·컨텍스트 메뉴 등 기존 동작은 그대로 유지된다.
6. **불필요한 아이콘 제거**: 사이드바 상단의 장식용 로고와, 설정 버튼과 기능이 겹치던 계정 아이콘을 없앤다.
