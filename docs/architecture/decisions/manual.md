# 설명서·갈무리

> 설명서 원본 관리와 갈무리 격리.
> 색인: [`../design-decisions.md`](../design-decisions.md).

## 설명서는 원본을 하나만 둔다 (v1.32)

GitHub에서 읽히는 마크다운과 앱이 F1으로 여는 HTML을 따로 쓰면 반드시 한쪽이
낡는다. `docs/manual.md`가 원본이고, `scripts/build_manual.py`가 그것을
`docs/manual/index.html`로 만든다.

마크다운 라이브러리를 새로 들이지 않았다 — 설명서가 쓰는 문법(제목·문단·목록·표·
인용·수평선·이미지·링크·굵게·인라인 코드)만 다루면 충분하고, 그만큼은 의존성을
늘릴 값어치가 없다. 대신 **다루지 못하는 문법은 조용히 글자로 나오므로**
(`| 키 | 동작 |`이 표가 아니라 문장으로 보이는 식) `tests/unit/test_build_manual.py`가
실제 설명서를 렌더해 "남은 마크다운이 없는가"와 "목차 링크가 실제 앵커를 가리키는가"를
고정한다.

**F1은 번들된 HTML을 먼저 찾는다.** 설치해 쓰는 앱이라 오프라인에서도 열려야 하고,
무엇보다 GitHub 문서는 이미 다음 버전을 설명하고 있을 수 있다. 번들에 없을 때만
저장소 문서로 보낸다(`gui/help.py`).

화면 갈무리는 `scripts/capture_screenshots.py`가 **임시 DB에 표본 자료를 심고 실제
앱 화면을 그려** 만든다. 손으로 찍으면 화면이 바뀔 때 조용히 낡고, 사용자의 실제
라이브러리가 찍힐 위험도 있다.

## 갈무리가 사용자의 즐겨찾기를 담아 배포됐다 (v1.32.1)

v1.32.0 설명서 갈무리에 **사용자의 실제 즐겨찾기 항목**이 찍혀 공개 저장소와 설치본에
들어갔다. 갈무리 스크립트는 임시 DB를 쓰고 있었는데도 그랬다.

이유는 이 앱에 사용자 자료가 사는 곳이 **셋**이기 때문이다.

| 무엇 | 어디 |
| --- | --- |
| 영상·다운로드 이력 등 | `config.settings.DATABASE_PATH` (= `DATA_DIR/library.db`) |
| 설정(테마·태그·브라우저 프로필 경로) | `DATA_DIR/config.yaml` |
| **즐겨찾기 바 항목** | **OS 사용자 데이터 경로** (`platformdirs.user_data_dir`) |

DB만 갈아끼우면 나머지 둘은 그대로 사용자 것을 읽는다. 특히 세 번째는 `DATA_DIR`
밖이라 "데이터 디렉터리를 옮긴다"는 발상으로도 잡히지 않는다 — 패키징 규칙("사용자
데이터는 `platformdirs`로")을 그 파일만 따르고 있어서 생긴 균열이다.

**해결**: `OVC_DATA_DIR` 환경 변수 하나를 세 곳이 함께 본다. 갈무리 스크립트가 그것만
세우면 DB·설정·즐겨찾기가 모두 샌드박스로 따라온다.

밟은 함정 둘:

1. **읽는 시점이 중요하다.** 경로 상수는 `config.settings`를 **불러올 때** 정해진다.
   스크립트 위쪽에 앱 모듈 임포트가 한 줄이라도 있으면 그 시점에 실제 경로가 굳어
   격리가 **조용히** 깨진다. 그래서 스크립트는 맨 위에서 환경 변수를 세우고 무거운
   임포트를 전부 `main()` 안으로 미루며, AST 검사가 이를 고정한다.
2. **샌드박스를 시스템 임시 폴더에 두면 다른 것이 샌다.** 윈도우의 `%TEMP%`는 사용자
   홈 아래라, 설정 화면이 저장 경로를 그대로 보여 주면서 이번엔 **사용자 이름**이 찍혔다.
   샌드박스를 `build/manual-sandbox/`(프로젝트 안)로 옮겨 해결했다.

회귀 시험은 `tests/unit/test_capture_isolation.py`다. 환경 변수를 읽는 곳을 하나라도
빼면 실패한다(실제로 빼 보고 확인했다). 변수가 없을 때 기본 경로가 그대로인지도 함께
고정한다 — 사용자 데이터가 엉뚱한 곳으로 옮겨지는 것이 더 큰 사고다.

덧붙여 다운로드 화면 갈무리가 **완전히 비어** 있었다. 표본 자료를 영상에만 심고
`download_history`에는 심지 않아서다. 빈 화면은 설명서에서 쓸모가 없다.
